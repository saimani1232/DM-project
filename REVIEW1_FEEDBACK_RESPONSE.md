## Corrections made since Review 1
These problems were found while re-checking the whole project before the final review:

1. **Optimiser search window was outside the data.** The old bounds were speed 30–90 mm/s and layer height 0.1–0.4 mm. The dataset (and Table 2 of the paper) actually covers speed 10–70 mm/s and layer heights 0.2 and 0.8 mm only. The old optimum, case studies, Pareto front and response surfaces were therefore extrapolations. All bounds are now read from the data, and layer height is treated as a two-level factor.
2. **The old optimiser had not found the optimum.** All three objectives returned 41.15 MPa, yet the sensitivity table showed 50.7 MPa at 100 % infill. Gradient polishing and early stopping on a piecewise-constant tree model were the cause. The optimiser now runs without gradient polishing and with the robust objective, and it is verified against exhaustive search.
3. **Model-reuse bug.** The cross-validation loop re-fitted the *same* model objects, so the "best model" used for parity plots, SHAP and optimisation had actually been trained on the last CV fold with a different scaler. Every split now trains an independent copy (`sklearn.base.clone`), and scaling sits inside the model pipeline.
4. **Best-model choice was hard-coded** (XGBoost). It is now selected by 5-fold CV R², which picks Histogram Gradient Boosting.
5. **SHAP values were in scaled units** (inputs 0–1, outputs scaled) and covered tensile strength only. They are now in MPa with real parameter values, for both targets.
6. **Reference-paper values were corrected.** The literature R² values in Table 7 had been copied wrongly (e.g. SVR 0.943/0.80 instead of 0.9215/0.8359; AdaBoost 0.80/0.81 instead of 0.8893/0.9126). The citation was also wrong: the paper is *Next Materials* 10 (2026) 101420, not "2024".
7. **Dataset description was corrected.** The paper states that the 383 samples were compiled from the literature (Section 2.5); they were not printed on the PRATI_AP machine. The report's parameter-range table was also wrong.
8. **Replicated ANNs now follow the paper:** Adam ANN with two tanh layers, lr 1e-3, batch 32, 1000 epochs; Bayesian ANN 2×20 tanh. The cross-validation is described correctly (plain shuffled K-fold, not "stratified").
9. **Unverifiable reference removed and reference #3 corrected** (title, pages 509–519, DOI 10.1007/s00170-014-5835-2).
10. **Added:** Taguchi L15 predictions for the paper's Table 3 combinations; a limitations section; self-checks in the pipeline; `README.md`; `requirements.txt`.
