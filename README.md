# Optimization and Machine Learning Prediction of Tensile and Compressive Strengths for Additively Manufactured ABS Automotive Components

Course project – *Introduction to Digital Manufacturing*

**Reference paper:** G.A. Munshi, V.M. Kulkarni, S. Yargatti, "Computation of tensile and compressive strengths of additively manufactured ABS material for automotive applications using ANN algorithms", *Next Materials* 10 (2026) 101420, https://doi.org/10.1016/j.nxmate.2025.101420 (PDF in `reference_paper/`).

## What the project does
1. Loads the 383-sample ABS dataset released with the reference paper (5 FDM parameters → tensile and compressive strength).
2. Replicates the paper's models (Adam-optimised ANN, Bayesian-regularised ANN) plus SVR, Decision Tree and AdaBoost, and adds four ensembles (Random Forest, Extra Trees, Histogram Gradient Boosting, XGBoost).
3. Evaluates every model with 9 regression metrics, using an 80/20 hold-out split and 5-fold cross-validation, and compares the results with Tables 4 and 7 of the paper.
4. Explains the predictions with permutation importance and SHAP. SHAP contributions are reported in MPa, both globally and for individual recipes.
5. Finds optimal process parameters with robust differential evolution, then runs a sensitivity analysis, two automotive case studies (brake pedal, door handle) and a strength vs print-time Pareto front.

## How to run
```bash
pip install -r requirements.txt
python run_project.py                       # full pipeline, ~2-3 min; regenerates outputs/
python report/build_report_docx.py          # Word version of the report (needs outputs/)
python presentation/build_presentation.py   # PowerPoint deck (needs outputs/)
python simulator/build_simulator.py         # interactive simulator (needs outputs/)
node simulator/test_runtime.js              # optional: checks the browser model equals the Python model
python simulator/run_feature_tests.py       # optional: 75 automated UI checks in headless Edge/Chrome (add --mobile for phone width)
```
At the end, `run_project.py` runs a set of self-checks: parameter bounds, optimum vs exhaustive search, reproducibility of reported predictions, and SHAP additivity. If any check fails, it exits with a non-zero code.

## Key results (generated by `run_project.py`)
- Best model (by 5-fold CV): **Histogram Gradient Boosting**. CV R² = 0.9995 for both strengths; CV RMSE = 0.25 MPa (tensile) and 0.31 MPa (compressive).
- Replicated Adam-ANN: hold-out R² = 0.985 / 0.974. This is in line with the paper's reported 0.93 / 0.98.
- Infill density dominates (≈62 % of mean |SHAP|), followed by layer height (≈23 %) and print speed (≈11 %). Bed temperature has practically no effect.
- Robust maximum-strength recipe: layer 0.2 mm, infill ≥ 95 %, speed ≤ 35 mm/s, nozzle ≈ 215–245 °C, any bed temperature. Predicted strengths: about 50.4 MPa tensile and 63.0 MPa compressive.

See `report/Project_Report.md` for the full discussion, including the comparison with the paper and the limitations.
